# 🛒 SAO - Office Supplies System

**SAO** It's an online store developed with traditional web technologies that allows for the sale of office supplies. It includes a product catalog, shopping cart, user system, and basic order management.

---

## 🌐 Technologies used

- **Frontend**
  - HTML5
  - CSS3 whit Bootstrap 5
  - JavaScript (vanilla)
  
- **Backend**
  - PHP 7+
  - MySQL 

---

## 📦 Main Features

- ✅ Product catalog with search
- 🛒 Dynamic shopping cart
- 🔐 User registration and login
- 📑 Order management by the administrator
- 📬 Generation of PDFs for statistics/reports
- 📊 Basic administration panel
